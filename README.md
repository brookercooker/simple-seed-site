# Simple Seed Site

Build a minimal single-page marketing site called "Pipeline Test" to use as a test harness for a chat-driven design workflow -- keep it intentionally simple. One page only: a nav bar with a logo/site name and a couple of placeholder links, a hero section with a headline, a short subheading, and a call-to-action button, and a simple footer with a copyright line. Use clean, modern styling with Tailwind and shadcn/ui, nothing elaborate. No backend, no auth, no extra pages needed yet -- this is a seed project that will be iterated on via further chat messages.

This project was built with [Lovable](https://lovable.dev).
